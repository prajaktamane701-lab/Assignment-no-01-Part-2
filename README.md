# Dr. Maya Reynolds Therapy Homepage

Redesigned from the supplied cloned counseling homepage while preserving the existing TanStack/Vite React architecture.

## Run

```bash
npm install
npm run dev
```

## Build check

```bash
npm run build
```

## Content note

The homepage uses the Dr. Maya Reynolds profile information available from the supplied profile source and matching profile material. No invented credentials, specialties, pricing, insurance policy, session duration, or treatment guarantees are included.

A real Dr. Reynolds portrait was not present as a usable image asset in the supplied project, so the About section contains a clearly marked portrait placement rather than falsely representing another person as Dr. Reynolds.
